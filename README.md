# CrediKhaata 💳

CrediKhaata is a modern React.js credit ledger management system designed for small shopkeepers who sell products on credit to customers.

The application helps manage:

* Customers
* Credit sales (Loans)
* Repayments
* Outstanding balances
* Due dates
* PDF statements

---

# 🚀 Features

## 🔐 Authentication

* Signup page
* Login page
* Mock authentication using localStorage
* Persistent login session
* Protected routes

## 📊 Dashboard

* Customer cards
* Outstanding balances
* Due dates
* Overdue indicators
* Responsive layout

## 👤 Customer Management

* Add customers
* View customer details
* Loan history
* Repayment history

## 💰 Loan Management

* Add loans/credit sales
* Due date tracking
* Outstanding balance calculation
* Overdue detection

## 💵 Repayment Management

* Add repayments
* Balance reduction logic
* Repayment history

## 🌙 Dark Mode

* Dark/Light theme toggle
* Theme persistence using localStorage

## 📄 PDF Export

* Download customer statements using jsPDF

## 📱 Responsive UI

* Mobile-first design
* Tablet support
* Desktop optimized

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/credi-khaata.git
```

## 2️⃣ Navigate to Project

```bash
cd credi-khaata
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Run Development Server

```bash
npm run dev
```
